# Речной катер

Аркада про катер на озере Неро: уворачивайся от препятствий, спасай людей, проплыви мимо ростовских монастырей и кремля.

Управление: на компьютере — стрелки или WASD (↑ газ, ↓ тормоз), на телефоне — касание левой/правой половины экрана для руля, ниже середины — газ, самый низ — тормоз. Пауза — P или Esc, звук — M.

Игра статическая: достаточно открыть `index.html` через любой веб-сервер (например, GitHub Pages).
